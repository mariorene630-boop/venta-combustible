# Venta Combustible — PWA

Aplicación web instalable para una sola bomba.

Incluye:
- Diésel, Súper y Regular.
- Numeración inicial/final.
- Precio por litro.
- Litros vendidos.
- Venta por combustible.
- Venta total.

## Uso en Android
La PWA necesita servirse por HTTPS para que el modo instalable y el funcionamiento offline estén disponibles.
Puedes subir esta carpeta a cualquier hosting estático HTTPS (por ejemplo GitHub Pages, Netlify o Vercel).
Luego abre la dirección en Chrome y selecciona "Agregar a pantalla de inicio".

También puedes abrir index.html directamente para usar la calculadora, aunque el modo PWA/offline completo requiere HTTPS.
